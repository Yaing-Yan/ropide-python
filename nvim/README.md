# rin.nvim

Neovim syntax highlighting and gadget completion for **RopIDE `.rin` scripts**
(fx-991CNX calculator ROP programs).

Highlight colors match the [rop-ide](https://ropide.pages.dev) web version
(`/home/yanshangxuan/rop-ide`, `parser.js` + `InputPanel.module.scss`);
gadget completion data comes from `gadgets.json` in the `.rin` project directory
(project folders generated by [ropide-python](https://github.com/human-coding/ropide-python)).

## Features

- Syntax highlighting: comments, constants `$a = 1234;`, gadgets `#pop-er0;`, value blocks `[expr]`, anchors `<x>` / `<-x>`, raw hex bytes
- Unknown gadgets (not in `gadgets.json`) are automatically marked as warnings (squiggly underline), matching the web version
- Completion (same auto-popup experience as Python completion): typing `#` pops up candidates, supports the `#-` prefix to auto-generate the 00-byte-forbidding `#-name;` form
  - Auto-adapts **blink.cmp** (LazyVim default) and **nvim-cmp** with no extra configuration; falls back to `<C-x><C-o>` omnifunc completion when neither is installed
- Automatically finds `gadgets.json` in the `.rin` file's directory (and up through parent directories)
- `:RinReload` reloads `gadgets.json` and refreshes highlighting
- Colors auto-adapt to the theme: light themes use the rop-ide web colors; dark themes use near-black dark backgrounds + bright foregrounds for valid blocks

## Requirements

- Neovim 0.8+ (or Vim 8.2+)
- Requires `filetype plugin on` (enabled by default in most configurations)

## Installation

### lazy.nvim (recommended)

```lua
-- ~/.config/nvim/lua/plugins/rin.lua
return {
  "yourname/rin.nvim",           -- replace with your actual GitHub repo URL
  ft = "rin",
  event = "VeryLazy",
  config = function() end,
}
```

Or with a local path (before uploading to GitHub):

```lua
return {
  dir = "/home/yanshangxuan/human-coding/ropide-python/nvim",
  name = "rin",
  ft = "rin",
  config = function() end,
}
```

### vim-plug

```vim
Plug 'yourname/rin.nvim'
```

### Manual (runtimepath only)

```vim
" init.vim / init.lua
set runtimepath+=/path/to/rin.nvim
filetype plugin on
```

## Usage

Opening any `*.rin` file enables it automatically (filetype auto-detection, completion source auto-registered).

Completion (auto-popup, same as Python completion):

1. Type `#` and the gadget candidate list pops up automatically (shows `0x address` and description)
2. Type part of the name to filter, e.g. `#po`
3. Use `<C-n>` / `<C-p>` to select, Enter inserts `#pop-er0;`
4. The `-` prefix (type `#-po`) auto-generates the 00-byte-forbidding `#-pop-er0;`

When blink.cmp / nvim-cmp is not installed, `<C-x><C-o>` still triggers the same completion.

After modifying `gadgets.json`, run in the `.rin` buffer:

```vim
:RinReload
```

## Highlight Groups

Colors are taken directly from rop-ide's `InputPanel.module.scss` and can be overridden in your colorscheme:

| Group | Meaning | Color |
|---|---|---|
| `rinComment` | `// comment` | #888 italic |
| `rinConstantName` | constant name `$a` | #0b7285 |
| `rinConstantEqual` | `=` | #343a40 |
| `rinConstantValue` | constant value `1234` | #5c940d |
| `rinConstantWarning` | invalid constant | + squiggle #d29200 |
| `rinGadgetClosed` | `#known gadget;` | #1864ab, bg #e7f5ff |
| `rinGadgetWarning` | `#unknown gadget;` | #1864ab + squiggle |
| `rinGadget` | unclosed `#name` | #1864ab |
| `rinValueClosed` | `[expression]` | #e67700, bg #fff9db |
| `rinValueWarning` | `[invalid content]` | #e67700 + squiggle |
| `rinValue` | unclosed `[` | #e67700 |
| `rinAnchorClosed` | `<x>` / `<-x>` | #087f5b, bg #e6fcf5 |
| `rinAnchor` | unclosed `<x` | #087f5b |
| `rinHex` | raw hex bytes | light theme #000 (bold) / dark theme follows Normal |

In dark themes (`&background=dark`), dark variants are used automatically: valid blocks use near-black backgrounds
(e.g. gadget #101f33, value #211a10, anchor #10241d) with bright foregrounds
(e.g. #4dabf7 / #ffa94d / #63e6be) to ensure readability.

## Directory Structure

```
rin.nvim/
├── ftdetect/rin.vim          *.rin → filetype rin
├── syntax/rin.vim            syntax definitions and highlight groups (light/dark palettes)
├── ftplugin/rin.vim          omnifunc, commentstring, :RinReload, completion source registration
├── lua/rin/completion.lua    completion source dispatcher (auto-detects blink.cmp / nvim-cmp)
├── lua/rin/blink.lua         blink.cmp completion source (LazyVim default)
├── lua/rin/cmp.lua           nvim-cmp completion source
└── autoload/rin/gadgets.vim  gadgets.json parsing and completion logic
```

## Notes

- The plugin root is `nvim/` itself (the directory containing this README); you can `git init` it directly and upload it as a repository
- Highlighting is a static regex approximation; forward references of constants/anchors (e.g. `[$c + 10]` with an undefined constant) are not marked as warnings, slightly different from the web version's deferred evaluation

# rin.nvim

(fx-991CNX 计算器 ROP 程序).

高亮配色与 [rop-ide](https://ropide.pages.dev) 网页版一致

## 功能

- 语法高亮：注释、常量 `$a = 1234;`、gadget `#pop-er0;`、数值块 `[expr]`、锚点 `<x>` / `<-x>`、裸 hex 字节

- `:RinReload` 重新加载 `gadgets.json` 并刷新高亮
- 配色自动适配主题：浅色主题按 rop-ide 网页版配色；深色主题下有效块使用接近黑色的深色底 + 亮色前景
